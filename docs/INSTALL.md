# binomen — installing and using it

For working biologists. No terminal, no Python, no NCBI download. If you can
install a browser extension, you can install this.

---

## What it does, in one paragraph

Organism names change. *Clostridium difficile* is now *Clostridioides
difficile*. *Enterobacter aerogenes* is now *Klebsiella aerogenes*.
*Lactobacillus* was split into about 25 genera in 2020. Both the old and the new
names are all over the literature, so a name looking familiar tells you nothing
about whether it is current — and searching PubMed for the current name alone
quietly misses decades of work, returning *few results* rather than an error.
binomen gives Claude a lookup table so it can check, instead of recalling.

Every answer comes from a dated copy of NCBI Taxonomy. Nothing is generated by
the model. If two authorities disagree, it says so rather than picking one.

---

## Before you start

- **Claude Desktop**, updated. Download it from <https://claude.ai/download>.
- **About 130 MB of free disk space** for the name index.
- **Windows or macOS.** Linux works too.
- **A few minutes** on first use, while the index downloads.

You do not need a Claude subscription tier beyond whatever you already use for
chatting, and you do not need an API key.

---

## Install

1. **Download the extension.**
   Go to <https://github.com/Nebraskinator/binomen/releases/latest> and download
   the file named **`binomen.mcpb`**. It is small — about 20 KB. It contains the
   program, not the data.

2. **Double-click it.**
   Claude Desktop opens and shows an install dialog describing what the
   extension does. Read it, then click **Install**.

   *If double-clicking does nothing:* open Claude Desktop, go to
   **Settings → Extensions → Advanced settings → Install Extension…**, and pick
   the file you downloaded.

3. **Restart Claude Desktop.** Quit it fully and reopen it.

4. **Ask it something.** In a new chat, type:

   > Is *Clostridium difficile* still the accepted name?

   The first time, binomen downloads its name index — about 46 MB, once. If it
   is not ready yet, it will say so plainly rather than guess. Wait a minute and
   ask again.

That's the whole installation.

---

## The permission prompt

The first time Claude uses one of binomen's tools, Claude Desktop asks your
permission. This is normal and it is the app protecting you, not a fault.

Click **Always approve** rather than **Allow once**. binomen only reads a file
on your own computer — it never writes anything, never deletes anything, and
makes no network requests when answering a question. Approving it once means you
will not be asked again for that tool.

You will see the prompt up to four times, once per tool, and then not again.

## Using it

binomen does not always speak up on its own. If a name matters to what you are
doing, **ask for it**. These all work:

> Check the name *Enterobacter aerogenes*.

> I'm writing a methods section about *Lactobacillus casei*. Is that name
> current, and what should I call it?

> Build me a PubMed search that covers everything published on
> *Clostridium difficile*, including under its older names.

> Here's a species column from my dataset — check every name in it and tell me
> which ones are out of date. [paste the list]

> These two papers use different genus names. Are they talking about the same
> organism?

If you want Claude to check names automatically throughout a conversation
without being asked each time, say so once at the start:

> For this whole conversation, check any organism name with binomen before you
> use it in a sentence.

---

## Reading the answers

binomen gives one of a few verdicts:

| verdict | meaning | what to do |
|---|---|---|
| **stable** | The name is the accepted one. | Nothing. Use it. |
| **superseded** | It is now a synonym; something else is accepted. | Use the accepted name, and search on both. |
| **homonym** | The same string names more than one organism. | You need more context — an authority or an ID — to say which you mean. |
| **contested** | Authorities genuinely disagree. | Say so in your writing. Do not silently pick one. |
| **unknown** | No record in this release of the index. | Not the same as "wrong". Could be a misspelling, an informal name, or newer than the index. |

Every answer carries the NCBI release it came from, like
`taxdump-2026-08-13`. If that date matters to your work — and for a manuscript
it does — quote it in your methods.

**"Superseded" does not mean the old name is wrong.** It means the accepted name
has changed. Papers published under the old name are still valid, still
findable, and still yours to cite. That is exactly why `expand_query` builds a
search covering all of them.

---

## Keeping it current

The index updates itself. binomen checks for a newer release every couple of
weeks, downloads it quietly in the background, and switches over the next time
you restart Claude Desktop. You do not have to do anything.

If your index gets badly out of date, binomen adds a line to its answers saying
so. It will not answer as of a date you have forgotten about without telling
you.

## If something goes wrong

**"Unable to connect to extension server."**
Restart Claude Desktop. If it persists, uninstall and reinstall the extension
from Settings → Extensions. Make sure you are on the latest release — versions
before 0.2.4 fail to start under some Claude Desktop configurations.

**It says the index is unavailable.**
It could not download the 46 MB index. Check your internet connection, then
restart Claude Desktop. On an institutional network, a proxy or firewall may be
blocking GitHub — worth asking your IT group.

**Claude answers about a name without checking.**
Ask it explicitly, using one of the prompts above. This is a known limitation,
not a broken install: the model decides when to reach for a tool, and it does
not always reach for this one.

**It disagrees with something you know to be true.**
It is reporting one dated release of NCBI Taxonomy, which is not the same thing
as the truth. NCBI can lag a published revision, and for some groups it
disagrees with the specialist database in that field. binomen's job is to tell
you what NCBI says, with a date on it, and to flag where authorities differ —
not to settle taxonomy.

**Still stuck.** Open an issue at
<https://github.com/Nebraskinator/binomen/issues>. Include your operating
system, your Claude Desktop version (Settings → About), and what you asked.

---

## Uninstalling

Settings → Extensions → binomen → Uninstall.

That removes the extension but leaves the downloaded index. To remove that too,
delete this folder:

- **Windows:** `%LOCALAPPDATA%\binomen`
- **macOS:** `~/Library/Application Support/binomen`
- **Linux:** `~/.local/share/binomen`

---

## What binomen does not do

Worth knowing before you rely on it.

- **It does not settle disputed taxonomy.** It reports disagreement; it does not
  resolve it.
- **It reports NCBI Taxonomy**, which is a pragmatic working classification, not
  a nomenclatural authority. For formal nomenclature, LPSN governs prokaryotes
  and IPNI/POWO govern plants.
- **It has no lineage or phylogeny.** No "what family is this in", no trees. The
  extension carries names and their history; that is all it is for.
- **It is only as current as its index.** A change published last week will not
  be there until NCBI picks it up and a new index is cut.
- **It cannot catch what you do not show it.** If a name never enters the
  conversation, nothing checks it.
